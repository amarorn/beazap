# Changelog

All notable changes to this project are documented in this file.

## Week of March 2-9, 2026

### Highlights
- Added contact base support with LID/send flow and context collection improvements.
- Shipped real-time translation support across backend and frontend, including LLM-based translation service and language-aware metrics/conversations.
- Added structured conversation feedback flow (service, API endpoint, and frontend client integration).
- Introduced automation flows support (backend service + API models/endpoints + frontend API methods).
- Implemented churn prediction capabilities (service, metrics endpoints, and frontend API integration).
- Added trends and anomalies analysis for emerging topics, metric anomalies, and sentiment anomalies.
- Improved onboarding/deployment scripts and Docker setup (installation/setup flow, PostgreSQL/Evolution service adjustments, static mounts, and environment fixes).
- Fixed operational/frontend issues including webhook URL handling, QR code rendering fallback, phone validation, CORS/Redis related fixes, and safer theme rendering in the sidebar.
